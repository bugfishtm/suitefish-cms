# 🐋 Docker

This folder contains files to build a Docker package for the software. **Caution**: This folder is not meant to be used by end-users. For docker deployment - please visit the suitefish-cms documentation or: https://hub.docker.com/r/bugfishtm/suitefish

**Developers**: This image is for developers, with real time sync between files. This is made via a direct folder mounted volume (_public) so developers can code and see the results immidiately without rebuilding.

**Productive**: This folder is used by the suitefish staff to build new docker images to deploy on dockerHub.
